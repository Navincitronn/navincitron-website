Equations and model assumptions

Source: SanHop MWD SN1103 Antenna SN1 Tuning Checksheet 261016, the shared MWD/Rotor receive topology, and Antenna_Engineering_Calculators (Series TX, Parallel RX, RF gain).

1. Antenna and checksheet

Lcase = Lair · CSLF; CSLF = Lcase / Lair
C = C(IN) + ΔC + Cparasitic + Cboard
f0 = 1/(2π√(LC)); Ctarget = 1/[(2πftarget)²L]; ΔCtarget = Ctarget − C
Rmeas = 2πfLCR L / QLCR
R(f) = RDC + max(0,Rmeas − RDC)(f/fLCR)^p + Rextra + Rrad
ω = 2πf; Zcoil = R + jωL; Qcoil = ωL/R

2. Parallel tank and receive response

Yintrinsic = jωC + 1/Rleak; Yload = Yintrinsic + 1/Rreceiver + (optional 1/ZU1)
Zout = 1/(1/Zcoil + Yintrinsic); Zin = 1/(1/Zcoil + Yload)
Hant = 1/(1 + Zcoil Yload)
fzero = sqrt(1/(LC) − R²/L²)/(2π) for constant R and no additional reactive load
fpeak = argmax |Hant|; fZpeak = argmax |Zin|
F1,F2: |H(F)| = |Hpeak| · 10^(−A/20); BW = F2−F1; Qloaded = fpeak/BW at half power
|Z| = √(Re²+Im²); phase = atan2(Im,Re); gain dB = 20 log10|H|

Numerical search and bisection locate peaks and cutoffs, including asymmetric responses. If a positive lower cutoff or peak does not exist, bandwidth is not assigned. The default A = 3.0103 dB.

3. SanHop U1, U3 and U5

s=jω; Z5=1/(sC5); Zp=1/(sC6+1/(Z5+R150)); ZU1=R154+Zp
Zf1=1/(1/R152+sC102)
H1=(1+Zf1/R151) · Zp/ZU1 · R150/(Z5+R150)
α=sCb/(1/Rb+sCb); Zf=1/(1/Rf+sCf); β=(1+Zf/Rg)α
Hstage=(β/Ri)/(1/Ri+sCa+(1−β)/Ra+sCb(1−α))
U3: Ri/Ra/Rb/Rf/Rg = R148/R5/R4/R141/R144; Ca/Cb/Cf=C7/C8/C98
U5: Ri/Ra/Rb/Rf/Rg = R6/R9/R135/R136/R134; Ca/Cb/Cf=C9/C92/C93
HTP60=H1; HTP3=H1H2; HTP5=H1H2H3
HADC=1/[1+s(RADC+Rout)CADC]; fc=1/[2π(RADC+Rout)CADC]
ZADC=1/[1/(RADC+Rout)+sCADC]; Hsystem=Hant H1 H2 H3 HADC

For stability: τb=RbCb, τf=RfCf, G=1/Ri+1/Ra, K=1+Rf/Rg. Denominator coefficients a0=G, a1=G(τb+τf)+Ca−τbK/Ra+Cb, a2=Gτbτf+Ca(τb+τf)−τbτf/Ra+Cbτf, a3=Caτbτf. Require all positive and a1a2>a0a3.

4. Magnetic coupling and TX

EMF = ω B N Aeff |cos θ|; Vout,rms = EMF |H|; Vpp = 2√2 Vrms
Icoil = VTX/|Zcoil|; IC=ωCVTX; Iport=VTX/|Zin|
Pcu=Icoil²RDC; Pcoil=Icoil²R; Pshunt=VTX² Re(Yload)
HTX=Zin/(Zin+Rsource); Vsource=VTX/|HTX|; Psource=Iport²Rsource
m=Icoil NAeff; Baxis=μ0 m/(2πd³) ≈ 2×10⁻⁷ m/d³

5. Series RLC

Rloop = RDC+Rac+Rrad+RESR+Rsource+Rother; Rport=RDC+Rac+Rrad+RESR
X=ωL−1/(ωC); Zport=Rport+jX; Zloop=Rloop+jX
Q=2πf0L/Rloop; Xcut=Rloop √(10^(A/10)−1)
F1,2=[√(Xcut²+4L/C) ∓ Xcut]/(4πL); BW=F2−F1
I=Vdrive/|Zloop|; VC=I/(ωC); IRX=EMF/|Zloop|; VCRX=IRX/(ωC); Pcu=I²(RDC+Rac)

6. RF matching and gain

λ=v/f; Γ=|(Z−Zref)/(Z+Zref)|; RL=−20log10 Γ; VSWR=(1+Γ)/(1−Γ)
ηm=1−Γ²; ηr=Rrad/(Rrad+Rloss); G=Dηr; Grealized=Gηnetworkηm
Gain dBi=10log10(G); Paccepted=Pavailable ηnetwork ηm; Pradiated=Paccepted ηr
Rrad,small loop≈320π⁴(NA/λ²)²; FSPL=20log10(4πd/λ) (far field only); Glink=Grealized ηorientation

Limitations

The measured 1 kHz inductance/Q are extrapolated using a selectable loss exponent. The 17.9 Ω winding DC resistance fails the checksheet's 16.8–17.8 Ω limit. 586.3 nF is measured C(IN), not the nominal 300 nF capacitor population. Additional parasitics and receiver shunt should not be counted twice. The supplied latest netlist is Rotor/IUBHO; the common RX topology is assumed. C98 is placed across R141 rather than the contradictory U1 node entry; R149 is DNI. The netlist says combined gain 100, while nominal individual gains multiply to 500 and the modeled values yield about 475 at 700 Hz. Confirm actual schematic and scope measurements before qualification. All models assume linear small-signal operation; PWM, magnetic saturation, casing geometry, actual radiation efficiency, temperature and ADC sample-and-hold are not simulated. F1/F2 here refer to cutoff frequencies, not the firmware's F1/F2 communication tones.
